## Overview

**WordWeaver** is a fast, lightweight text analysis and manipulation web application built with **React** and **Bootstrap**. It empowers writers, developers, and content creators to instantly clean, analyze, transform, and listen to text in real time.

## The Challenge

Writers and developers frequently need to perform repetitive text cleanup tasks — converting cases, stripping excess whitespace, extracting links or numbers, and checking reading statistics — without installing heavy software or risking data privacy on shady online converters.

## The Solution

Created an in-browser utility built with client-side React. All processing occurs locally in the user's browser, guaranteeing privacy, zero latency, and instant visual feedback with live reading statistics.

## Key Features

- **Text Transformations** — Instant conversion to UPPERCASE, lowercase, Title Case, and removal of redundant whitespaces.
- **Pattern Extraction** — Quickly isolates numbers, letters, or URLs from raw text blocks.
- **Text-to-Speech** — Integrated browser Speech Synthesis API to read text aloud with play and stop controls.
- **Live Summary Metrics** — Real-time word count, character count, and estimated reading time.
- **Dark Mode Support** — Built-in theme switcher for comfortable usage in any lighting.

## Technical Highlights

- **Framework**: React 18, JavaScript
- **Styling**: Bootstrap 5
- **APIs**: Web Speech API (SpeechSynthesis), Clipboard API
