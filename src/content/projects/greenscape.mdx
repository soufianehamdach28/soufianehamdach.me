## Overview

**GreenScape** is a modern, high-conversion commercial website and portfolio platform for landscaping and outdoor design services, built with Next.js and Tailwind CSS.

## The Challenge

High-end service businesses need websites that convey craftsmanship, visual elegance, and seamless responsiveness to turn visitors into quote inquiries:

- Creating fluid, smooth scroll-driven animations without degrading mobile performance
- Designing a mobile-first UI with responsive typography and optimized media assets
- Structuring clean dynamic routes for service catalogs and past project galleries

## The Solution

Developed an interactive web experience utilizing **Next.js App Router**, **TypeScript**, and **Tailwind CSS**. Integrated performance-tuned motion and scroll triggers that highlight project transformations, paired with an accessible service inquiry flow.

## Key Features

- **Interactive Scroll Animations** — Engaging transitions showcasing before-and-after outdoor transformations.
- **Dynamic Project Galleries** — Categorized showcases for residential, commercial, and hardscaping projects.
- **Mobile-First Responsiveness** — Optimized for fast load times and touch interactions on smartphones and tablets.
- **SEO & Performance** — Server-rendered architecture with structured metadata for maximum local search visibility.

## Technical Highlights

- **Framework**: Next.js (App Router), React, TypeScript
- **Styling & Motion**: Tailwind CSS, CSS animations
- **Architecture**: Static Site Generation (SSG), dynamic routing
